# 第 1 讲：课程地图与椭圆曲线

- 事故：币安 2026、Bitget 2026
- 语言：Python

## 练习

打开 `exercise/ecc.py`，把每个 `raise NotImplementedError` 换成你的代码：

1. `inv`：模 p 下的逆元
2. `add`：曲线 y² = x³ + 7 上的点加法
3. `mul`：标量乘法 k·G
4. `brute_force`：在 mod 17 的小曲线上，从公钥倒推私钥
5. 用同一套 `add` 和 `mul` 算 secp256k1 上的 2G
6. 进阶：`address`，私钥 → 以太坊地址

第 4 题在 18 个点的曲线上一下就能试完；secp256k1 有约 2²⁵⁶ 个点，同样的方法试不完。这就是私钥安全的来源。

### 和讲解里说的不一样的地方

讲解最后的练习段和本仓库的练习有几处出入，**以本仓库的代码和判分测试为准**。

函数名对照：

| 讲解里的名字 | 仓库里的函数 | 说明 |
|---|---|---|
| `inv_mod` | `inv(a, p)` | 模 p 下的逆元 |
| `point_add` | `add(A, B, p)` | 点加法，含倍点和无穷远点（`None`） |
| `scalar_mult` | `mul(k, A, p)` | 用倍加法算 k·A |
| `pubkey_to_address` | `address(priv)` | 输入是**私钥**，函数内部先算公钥再算地址 |
| （讲解里没有） | `brute_force(Q)` | 在小曲线上从 1 开始试，求出私钥 |

其他区别：

- **地址的大小写**：讲解里说要带 EIP-55 校验，结果写作 `0x7E5F…5Bdf`；判分测试要求返回全小写，即 `0x7e5f4552091a69125d5dfcb7b8c2659029395bdf`。想练 EIP-55 的话，可以在 `address` 之外另写一个函数。
- **哪些是必做**：讲解里地址生成是必做、小步大步算法是进阶；仓库里第 1–5 题必做，第 6 题 `address` 是进阶，暴力求私钥 `brute_force` 是必做。小步大步算法目前仓库里没有对应的题，可以自己在 `brute_force` 的基础上改写。
- **哈希函数**：讲解里提醒不要用 `hashlib.sha3_256`，这一条仍然成立。以太坊用的是 Keccak-256，练习文件里已经导入了 `Crypto.Hash.keccak`。

## Fork 解答笔记

- 小曲线上用 `None` 表示无穷远点。枚举从 `1G` 开始，第一次回到无穷远点是 `18G`，因此当目标为 `None` 时，最小正整数解是 18。
- 以太坊地址派生先计算公钥，再将两个 32 字节坐标拼接后计算 Keccak-256，取哈希末尾 20 字节作为地址。
- 在仓库根目录执行上面的判分命令即可测试 fork 的练习实现。若此前设置过 `GXA_SOLUTION`，先清除该环境变量，以便测试实际解答。
